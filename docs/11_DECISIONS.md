## 2. 설계 결정 기록 (ADR)

형식: 맥락 → 결정 → 결과(장단) → 대안. 새 결정은 번호를 이어 붙인다.

### ADR-01 원점 재구축 (이관 아님)
- **맥락:** 기존 코드는 Vercel·Neon·Upstash 전제. 사내 이관에 덧대기·이관 도구·DB 서버 설치가 필요했다.
- **결정:** 새 리포에서 다시 만든다. 기존 리포는 규칙·문구·UAT 참고용.
- **결과:** 클라우드 계층 전부 제거. 기존 테스트 286건은 재사용하지 않고 규칙만 옮긴다.

### ADR-02 런타임 Node.js 포터블
- **맥락:** 서버에 Python 없음(설치 승인 필요). 기존 운영 앱은 Node + NSSM. 공용 Node 버전 미확인.
- **결정:** Node LTS 포터블 zip을 앱 폴더에 둔다. 공용 Node 미사용.
- **결과:** 설치 프로그램·PATH 변경 없음. 런타임 업데이트는 우리가 책임(새 폴더에 풀고 NSSM Application 경로 교체).
- **대안:** Python 3.11(설치 필요) · 공용 Node(버전 미확인·공유 위험).

### ADR-03 DB는 내장 SQLite
- **맥락:** 사용자 수십 명. PostgreSQL은 설치·계정·백업 도구·서비스가 추가된다.
- **결정:** `node:sqlite` + WAL 파일 하나.
- **결과:** DB 관리 = 파일 관리. 단일 프로세스 제약(문제 없음).
- **대안:** `better-sqlite3`(네이티브 · 사전 빌드 의존) — `node:sqlite` 정책상 불가 시에만 · PostgreSQL — 기각.

### ADR-04 Express 5, 빌드 없는 화면
- **결정:** Express 하나 + 정적 HTML/바닐라 JS.
- **결과:** `npm ci` 뒤 바로 실행 · 코딩 에이전트 친화. 화면 생산성은 프레임워크보다 낮지만 화면 수가 10여 개라 감당 가능.
- **대안:** Next.js(빌드·`.next`·standalone 계약) · React+Vite(빌드 단계) — 기각.

### ADR-05 로그인은 1인 1코드 + 서버 세션
- **맥락:** 기존엔 관리 토큰·공용 열람 코드·개인 코드 세 가지가 병존.
- **결정:** 개인 코드 하나로 통일. 세션은 DB 저장(즉시 폐기 가능). 서명 키는 앱 자동 생성.
- **결과:** 공용 코드 공유 문제 제거. 코드 전달은 사람(사내 메일).

### ADR-06 이메일 저장 안 함
- **맥락:** 기존 헌법은 "이메일은 로그인·알림에만". 재구축판은 메일 발송이 없고 로그인은 코드.
- **결정:** 명단의 이메일 열을 버린다. DB에 이메일 칸 없음.
- **결과:** 개인정보 면적 축소. 사무국은 자기 명단 원본으로 메일을 보낸다.

### ADR-07 자료 PDF 변환은 서버 밖
- **결정:** 사무국 PC 도구가 워터마크 webp 꾸러미를 만들고 서버는 받기만.
- **결과:** 서버에 poppler·이미지 라이브러리·글꼴 불필요. 서버에 PDF 원본이 존재하지 않음.

### ADR-08 업로드는 zip 원문 본문
- **결정:** 멀티파트 대신 `application/zip` 본문 · 내장 zlib로 읽는 최소 zip 리더.
- **결과:** 의존성 0. zip64·암호화 zip은 미지원(꾸러미 도구가 만들지 않음).

### ADR-09 HTTPS는 앱 밖
- **결정:** 앱은 HTTP만. HTTPS는 승인된 리버스 프록시가 담당, 앱은 `TRUST_PROXY`로 대응.
- **결과:** 인증서 관리 부담 없음. 1단계 HTTP 개통은 별도 승인(B3).

### ADR-10 커뮤니티 확장은 추가형 · 기능 플래그
- **맥락:** P4 기본 게시판만으로는 재방문 동기가 약하다. 기능을 붙이면서 기존 구조가 흔들리면 안 된다.
- **결정:** 확장 14종을 `docs/13` 규칙(새 마이그레이션의 표·칸 추가만 · 기능별 라우트 파일 · `features.<키>` 게이트)으로만 붙인다. 기존 코드 접점은 `app.js` 한 줄, 글 저장 훅 1개, 기존 응답에 칸 추가뿐이다.
- **결과:** 기능별로 켜고 끌 수 있고, 꺼진 상태에서 P0~P4 동작이 그대로다(회귀 테스트로 확인). 마이그레이션 2~3개가 늘어난다.
- **대안:** 기존 표 재설계(구조 변경) · 플러그인 로더(과설계) — 기각.

### ADR-11 알림은 앱 안 · "마지막 확인 시각"만
- **맥락:** 재방문 신호가 필요하지만 메일 발송은 금지, 열람 이력은 개인 행동 기록이 된다.
- **결정:** 사람·공간당 마지막 확인 시각 1개(`seen`)로 새 글 수를 계산한다. 폴링 30초 이상. WebSocket 없음.
- **결과:** 읽은 글 목록이 남지 않는다. 정확도는 "공간 단위"로 충분.

### ADR-12 판정 경계 기능은 기본 꺼짐
- **결정:** "도움됐어요"·설문은 마이그레이션 004와 함께 결정 B8·B9 승인 뒤에만 릴리스에 넣고, 켜도 정렬·사람별 통계·명단을 만들지 않는다.
- **결과:** 헌법 1조 위반 위험을 기본값에서 0으로 둔다.
